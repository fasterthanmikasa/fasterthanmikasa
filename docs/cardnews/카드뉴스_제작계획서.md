## 1. 기획 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | 생활배구 웹 소개 카드뉴스 시리즈 (가제: **「배구, 더 쉽게」**) |
| 목적 | ① 생활배구 웹의 존재를 알린다 ② 핵심 기능을 하나씩 이해시킨다 ③ 실제 방문·가입(사용)으로 연결한다 |
| 채널 | 인스타그램 피드 (캐러셀 게시물) + 스토리 재공유 |
| 주요 타깃 | 생활배구를 하는 학생·학교스포츠클럽, 지도 교사, 동호회/생활체육 참가자 `[타깃 확정 필요]` |
| 형식 | 시리즈물 총 **8편** (티저 1 + 본편 6 + 마무리 1) |
| 기간 | 약 4주 (주 2회 발행) |
| 핵심 메시지 | "생활배구에 필요한 것, 이 웹 하나로." `[슬로건 확정 필요]` |

### 왜 시리즈인가?
- 한 게시물에 모든 기능을 담으면 장수가 길어지고 저장·공유율이 떨어짐
- 편마다 **한 가지 메시지**만 전달 → 이해도↑, 기억↑
- "다음 편 예고"로 팔로우·재방문 유도, 계정에 꾸준한 게시 흐름 확보

## 2. 시리즈 구성 (전체 로드맵)

| 편 | 제목(가제) | 역할 | 핵심 메시지 | 장수 |
|---|---|---|---|---|
| **EP.0** | 배구, 혹시 어렵게 느껴졌나요? | 티저·공감 | 생활배구를 하며 겪는 불편함을 짚고 "곧 해결책 공개" | 4~5장 |
| **EP.1** | 생활배구 웹을 소개합니다 | 전체 소개 | 웹이 무엇이고 누구를 위한 것인지 한눈에 | 7~8장 |
| **EP.2** | 기능 ① `[예: 규칙·경기 방법 안내]` | 기능 상세 | 헷갈리던 규칙, 여기서 바로 확인 | 6~8장 |
| **EP.3** | 기능 ② `[예: 경기 기록·점수판]` | 기능 상세 | 경기 중에도 쉽게 기록하고 결과 공유 | 6~8장 |
| **EP.4** | 기능 ③ `[예: 팀·선수 관리]` | 기능 상세 | 우리 팀 정보를 한곳에서 관리 | 6~8장 |
| **EP.5** | 기능 ④ `[예: 연습 방법·훈련 자료]` | 기능 상세 | 혼자서도, 팀으로도 실력 향상 | 6~8장 |
| **EP.6** | 3분 만에 시작하기 | 사용법 튜토리얼 | 접속 → 시작 → 첫 사용까지 따라 하기 | 8~10장 |
| **EP.7** | 이렇게 쓰고 있어요 + 총정리 | 활용 사례·CTA | 실제 사용 장면, 전체 기능 요약, 지금 바로 방문 | 7~8장 |

> 기능 편(EP.2~5)은 웹의 실제 핵심 기능 수에 맞춰 늘리거나 줄입니다. 기능이 3개면 총 7편, 5개면 총 9편.
> 기능 우선순위: **사용자가 가장 많이 쓸 기능 → 다른 곳에 없는 차별화 기능** 순으로 배치.

## 3. 편별 상세 기획 (슬라이드 단위)

### 공통 뼈대
모든 편은 아래 구조를 따릅니다.

1. **표지(훅)** — 시리즈 로고 + 편 번호 + 질문/공감형 제목
2. **문제 제기** — "이런 적 있지 않나요?"
3. **해결/본문** — 기능·정보 전달 (1장 1메시지)
4. **요약** — 핵심 3줄 정리 (저장 유도용)
5. **CTA + 다음 편 예고** — 프로필 링크 안내, "다음 편: ○○"

---

### EP.0 티저 — 「배구, 혹시 어렵게 느껴졌나요?」
| 장 | 내용 |
|---|---|
| 1 | 표지: "배구, 하고 싶은데… 어렵게 느껴진 적 있나요?" |
| 2 | 공감 ①: 규칙이 헷갈린다 `[실제 불편함으로 교체]` |
| 3 | 공감 ②: 점수·기록 관리가 번거롭다 |
| 4 | 공감 ③: 함께 연습할 자료가 부족하다 |
| 5 | "그래서 준비했습니다. ○월 ○일 공개" + 팔로우 유도 |

### EP.1 — 「생활배구 웹을 소개합니다」
| 장 | 내용 |
|---|---|
| 1 | 표지: "생활배구, 이제 이 웹 하나로" |
| 2 | 생활배구 웹이란? (한 문장 정의) |
| 3 | 누구를 위한 웹인가? (학생 / 교사 / 동호회 아이콘) |
| 4 | 주요 기능 한눈에 보기 (기능 4개 아이콘 그리드) |
| 5 | 메인 화면 스크린샷 (휴대폰 목업) |
| 6 | 이런 점이 좋아요 (무료·설치 불필요·모바일 OK 등) `[사실 확인 필요]` |
| 7 | 접속 방법: 프로필 링크 / URL / QR |
| 8 | 다음 편 예고: "EP.2 ○○ 기능 파헤치기" |

### EP.2 ~ EP.5 — 기능 상세 편 (공통 템플릿)
| 장 | 내용 |
|---|---|
| 1 | 표지: 질문형 제목 (예: "서브 순서, 매번 헷갈리죠?") |
| 2 | 문제 상황 (일러스트 또는 상황 묘사) |
| 3 | 해결: "○○ 기능이면 됩니다" + 기능 화면 |
| 4 | 사용 방법 STEP 1 (스크린샷 + 화살표 표시) |
| 5 | 사용 방법 STEP 2 |
| 6 | 꿀팁 / 이런 상황에서도 활용 |
| 7 | 3줄 요약 (저장해 두고 보세요) |
| 8 | CTA + 다음 편 예고 |

### EP.6 — 「3분 만에 시작하기」
| 장 | 내용 |
|---|---|
| 1 | 표지: "처음이어도 3분이면 충분해요" |
| 2~8 | STEP별 화면 캡처 (접속 → 시작/로그인 → 주요 메뉴 → 첫 기능 사용) |
| 9 | 자주 묻는 질문 2~3개 |
| 10 | CTA: "지금 바로 시작해 보세요" |

### EP.7 — 「이렇게 쓰고 있어요 + 총정리」
| 장 | 내용 |
|---|---|
| 1 | 표지: "생활배구 웹, 실제로 이렇게 씁니다" |
| 2~4 | 활용 사례 (수업 / 스포츠클럽 / 대회 준비 등) — 실제 사례·후기 확보 시 사용 `[후기 수집 필요]` |
| 5 | 전체 기능 총정리 (시리즈 썸네일 모음) |
| 6 | 시리즈 다시 보기 안내 (하이라이트 / 고정 게시물) |
| 7 | 최종 CTA: URL·QR + 공유·저장 유도 |
| 8 | 감사 인사 + 피드백 요청 ("원하는 기능을 댓글로 알려주세요") |

## 4. 디자인 가이드 (시리즈 통일성)

### 규격
- **사이즈: 1080 × 1350px (4:5 세로형)** — 피드에서 화면을 가장 넓게 차지
- 프로필 그리드는 3:4로 잘려 보이므로, **표지의 제목·핵심 요소는 위아래 여백을 두고 가운데 배치**
- 캐러셀 장수: 편당 5~10장 권장 (최대 20장까지 가능하나 이탈률 고려)
- 파일 형식: PNG(텍스트 선명) 또는 고화질 JPG

### 비주얼 아이덴티티
| 요소 | 가이드 |
|---|---|
| 메인 컬러 | `[웹 메인 컬러]` — 웹과 같은 색을 써야 방문 시 같은 서비스임을 인지 |
| 보조 컬러 | 활력 있는 포인트 1색 (예: 배구공 노랑/파랑 계열) |
| 폰트 | 제목: 굵은 고딕 (예: Pretendard Bold, G마켓 산스) / 본문: Pretendard Regular — 상업 이용 가능 무료 폰트 사용 |
| 글자 크기 | 제목 80~100px 이상, 본문 40px 이상 (휴대폰에서 읽히는 크기) |
| 시리즈 표식 | 모든 표지 좌상단에 `배구, 더 쉽게 EP.0X` 배지 고정 |
| 하단 바 | 매 장 하단에 계정명 + 페이지 표시(예: 3/8) |
| 화면 이미지 | 웹 스크린샷은 휴대폰 목업에 넣고, 강조 부분은 동그라미·화살표 표시 |
| 일러스트/아이콘 | 한 가지 스타일로 통일 (라인형 또는 플랫형 중 택1) |

### 표지 디자인 원칙
- 텍스트는 **최대 2줄, 15자 내외**
- 시리즈 전체 표지를 같은 레이아웃으로 → 프로필 그리드에서 시리즈가 한눈에 보이게
- 편마다 배경 색 또는 포인트 이미지만 바꿔 구분

### 제작 도구 (택1)
- **미리캔버스 / 캔바**: 템플릿 기반, 빠른 제작, 협업 쉬움 (추천)
- **Figma**: 템플릿을 컴포넌트화해 시리즈 통일성 유지에 유리

## 5. 카피(문구) 가이드

- **톤**: 친근한 존댓말 ("~해요", "~죠?"), 운동장 옆 선배가 알려주는 느낌
- 1장 = 1메시지, 한 장에 문장 3줄 이내
- 표지는 **질문형·공감형**: "○○ 때문에 고민이죠?", "아직도 ○○하세요?"
- 전문 용어는 처음 나올 때 쉬운 말로 풀이
- 숫자 활용: "3분 만에", "4가지 기능", "STEP 1·2·3"

[시리즈 안내]
#배구더쉽게 시리즈 EP.02 / 다음 편: ○○ (○/○ 업로드)

| 편별 | 해당 편 기능 관련 (예: #배구점수 #배구기록) |

## 7. 발행 일정 (예시: 4주)

| 주차 | 화요일 | 목요일 | 스토리 |
|---|---|---|---|
| 1주 | EP.0 티저 | EP.1 소개 | 티저 재공유 + "공개 D-day" 카운트다운 |
| 2주 | EP.2 기능① | EP.3 기능② | 퀴즈·투표 스티커 ("이 규칙 알았다/몰랐다") |
| 3주 | EP.4 기능③ | EP.5 기능④ | 질문 스티커로 궁금한 점 수집 |
| 4주 | EP.6 튜토리얼 | EP.7 총정리 | 시리즈 하이라이트 묶기 |

- 업로드 시간: 타깃이 휴대폰을 보는 시간대 (학생 대상이면 방과 후·저녁 시간대)로 시작하고, 1~2주 차 인사이트를 보고 조정
- 시리즈 종료 후: EP.1과 EP.6을 **프로필 상단 고정**, 스토리 하이라이트 「생활배구 웹」 생성
- 제작은 **발행 1주 전까지 완료** 원칙 (검수 시간 확보)

## 8. 제작 프로세스 & 체크리스트

### 편당 제작 흐름
1. 기획: 해당 편 핵심 메시지 1문장 확정
2. 자료 수집: 웹 화면 캡처 (실제 데이터 또는 예시 데이터로, 개인정보 노출 주의)
3. 카피 작성: 장별 문구 작성 → 소리 내어 읽어 보기
4. 디자인: 공통 템플릿에 적용
5. 검수: 아래 체크리스트 확인
6. 발행 & 스토리 공유
7. 3일 후 성과 기록

### 발행 전 체크리스트
- [ ] 표지 제목이 2줄·15자 내외인가?
- [ ] 1장에 1메시지만 담았는가?
- [ ] 맞춤법·띄어쓰기 확인 (맞춤법 검사기 사용)
- [ ] 스크린샷에 학생 이름 등 **개인정보**가 보이지 않는가?
- [ ] 사진 속 인물이 있다면 **초상권 동의**를 받았는가? (학생은 보호자 동의 포함)
- [ ] 폰트·이미지·아이콘이 **상업적 이용 가능** 라이선스인가?
- [ ] 시리즈 배지·페이지 번호·계정명이 모든 장에 있는가?
- [ ] 웹 URL·QR이 실제로 작동하는가?
- [ ] 휴대폰에서 직접 미리 보고 글자가 잘 읽히는가?
- [ ] 캡션에 CTA·시리즈 안내·해시태그가 들어갔는가?

## 9. 성과 측정

| 지표 | 의미 | 목표(예시) `[기준 설정 필요]` |
|---|---|---|
| 저장 수 | 정보가 유용했는지 | 편당 저장 ○건 |
| 공유 수 | 남에게 알릴 만했는지 | 편당 공유 ○건 |
| 도달/노출 | 얼마나 퍼졌는지 | 팔로워 대비 ○% |
| 프로필 방문·링크 클릭 | 실제 웹 방문으로 이어졌는지 | 시리즈 전체 클릭 ○건 |
| 팔로워 증가 | 시리즈 관심도 | 시리즈 기간 +○명 |
| 웹 방문자 수 | 최종 목적 달성 여부 | 시리즈 전후 비교 |

- 링크에 UTM 파라미터(예: `?utm_source=instagram&utm_campaign=cardnews_ep2`)를 붙이면 **어느 편에서 방문이 왔는지** 웹 통계에서 구분 가능
- 2주 차 종료 시 중간 점검 → 반응 좋은 편의 형식(질문형 표지, 튜토리얼형 등)을 남은 편에 반영

## 10. 확인 필요 사항 (제작 전 채워 주세요)

1. **웹의 핵심 기능 목록**과 우선순위 (기능 편 구성의 기준)
2. 웹 **URL**, 서비스 이름, 로고, 메인 컬러
